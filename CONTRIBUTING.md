# Contributing to Ocean Literacy

We welcome contributions from marine educators, software engineers, and ocean advocates worldwide.

## How to Contribute

1. **Fork the Repository:** Create a personal fork on GitHub.
2. **Create a Feature Branch:** `git checkout -b feat/your-feature-name`
3. **Run Verification:** Ensure all tests pass:
   ```bash
   npm test
   ```
4. **Commit Following Conventional Guidelines:**
   - `feat:` for new capabilities or modules
   - `fix:` for bug fixes
   - `docs:` for documentation updates
   - `chore:` for maintenance
5. **Open a Pull Request:** Submit your PR with a clear summary of changes.

Thank you for helping protect and advance our global ocean!
